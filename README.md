# ❄️ Guía Web de Buenas Prácticas en Instalación de Aires Acondicionados

Este proyecto fue generado con la ayuda de **Amazon Q Developer**.  
El reto consistió en pedirle a la IA que construya una **app web sencilla** que sirva como guía para:

- ✅ Buenas prácticas de instalación.  
- 🔧 Solución a problemas comunes.  
- 📊 Tabla de presiones de refrigerantes.  
- ⚡ Consumo y cálculo de amperaje.  

---

## 🚀 ¿Qué construí?

La aplicación es una **web informativa** con secciones clave para técnicos y estudiantes:

1. **Inicio** → acceso rápido a cada sección.  
2. **Buenas prácticas** → checklist y pasos recomendados en la instalación.  
3. **Solución de problemas** → guía básica para fallas comunes.  
4. **Tabla PT de refrigerantes** → tabla interactiva o en PDF (R-410A, R-32, etc.).  
5. **Calculadora eléctrica** → consumo estimado y amperaje según potencia/voltaje.
